# 3.0 Org chart: plan

Spec: `docs/superpowers/specs/2026-11-10-org-chart-design.md`.

**Goal:** a time-based org chart of seats and the people who hold them, built from what the directory and people's own profiles already say, that can be read on any date.

## Task 1: design spec (#39)

- [x] Spec written, with the brainstorm's questions decided on a recommendation and listed for confirmation.

## Task 2: schema and builder (#40)

- [x] `schema/organization.schema.json`: units, posts, holders, reporting lines and vacancies, all dated; a source on every post, holder and line.
- [x] `lib/orgchart/index.mjs`: `validateOrganization`, `stateOn` (filled, vacant, planned from the dates), `compareDates`.
- [x] `lib/orgchart/build.mjs`: from a folder of profiles and a directory export, honoring audiences through the same release directory sync makes; `--base` carries a file forward and never deletes.
- [x] `orgchart validate | build | show` (table and CSV).
- [x] A profile's dated `positions` are read into history when a seat is first built: earlier positions become ended posts the next one succeeds, sourced to the profile.

## Task 3: visualizer (#41)

- [x] `orgchart show --format html`: one self-contained page, a tree you move through with the keyboard and a screen reader, light and dark, vacant and planned marked in words and by pattern; `--compare` for two dates.
- [x] `--format pdf`: a tagged PDF through Typst, checked by veraPDF and the text-order check in CI; `table` and `csv` are the accessible table.
- [x] Checked in a browser (Chromium): keyboard, tree roles, both themes, reflow at 320 pixels, the list without scripting.
- [ ] Not done: a screen reader pass; an automated accessibility scan; a drawn box-and-line view (a decision to confirm); choosing a date inside the page (it is made for one date, or two with `--compare`).

## Task 4: analytics (#42)

- [x] `orgchart stats`: headcount and vacancies per unit, span of control, layers; headcount over a range of dates; a change log; budgeted against filled with `--budget`.
